Konsep Singkat Game of Life

Game of Life adalah simulasi sel berbasis grid dengan aturan:

Sel hidup dengan < 2 tetangga → mati (kesepian)

Sel hidup dengan 2 atau 3 tetangga → tetap hidup

Sel hidup dengan > 3 tetangga → mati (kelebihan populasi)

Sel mati dengan tepat 3 tetangga → hidup

untuk hasil akhir dari simulasi game of life ini ada pada file bernama "game of life array_adt".
untuk hasil simulasi dengan contoh nya ada di file bernama "game of life final".
